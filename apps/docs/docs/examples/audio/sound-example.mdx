# Sound Example

This example demonstrates the basic audio system capabilities. You can:

- Play a sound effect by clicking the 'Play Once' button
- Adjust the sound volume using the volume slider (range 0-1)
- Toggle audio on/off using the audio toggle button
- Play multiple instances of the same sound simultaneously
- Loop sounds for background music

The audio system uses the [Howler.js](https://howlerjs.com/) library under the hood.

```ts
const pack = new TResourcePack(engine, { sounds: [sound] });
await pack.load();
const clip = engine.resources.get<TSound>(sound)!;

clip.volume = 0.3;
clip.loop = true;
clip.play();
```

import { Suspense, use } from 'react';
import { browser } from 'react-dom';
import { TGame } from '@tedengine/ted';

export const Game = () => {
  use(browser());
  return (
    <TGame
      game={
        new Worker(new URL('@examples/audio/sound-example.ts', import.meta.url))
      }
      config={{
        showAudioToggle: true,
      }}
    />
  );
};

<Suspense fallback={null}>
  <Game />
</Suspense>
