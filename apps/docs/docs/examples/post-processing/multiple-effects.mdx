# Multiple effects

You can apply multiple post-processing effects. This example uses grayscale and film grain, each effect processes the output of the previous one.

Use the debug controls to adjust or disable them independently.

```ts
const grayscale = await TGrayscalePostProcessingEffect.create(this.jobs);
const filmGrain = await TFilmGrainPostProcessingEffect.create(this.jobs, {
  amount: 0.06,
  grainSize: 1,
  speed: 1,
});

this.postProcessing.add(grayscale);
this.postProcessing.add(filmGrain);
```

Effects run in the order they are added.
